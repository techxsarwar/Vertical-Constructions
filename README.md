## 🏛️ Project Vision

**Vertical Constructions** is not a template. It is a production-grade, AI-supercharged, full-stack platform designed to digitize the entire client-facing and operations layer of a luxury construction firm.

The architecture solves a real-world problem: **how do you manage a premium construction business website from anywhere in the world, with zero technical overhead?**

The answer: **a Telegram Bot that IS your CMS, your AI assistant, your analytics dashboard, and your broadcasting tool — all at once.**

## ⚡ Quick Start

### Prerequisites

```bash
node >= 18.x
python >= 3.11
git
```

### 1. Clone the Repository

```bash
git clone https://github.com/techxsarwar/Vertical-Constructions.git
cd Vertical-Constructions
```

### 2. Setup the Backend

```bash
cd backend

# Create virtual environment
python -m venv venv
venv\Scripts\activate       # Windows
# source venv/bin/activate  # macOS/Linux

# Install dependencies
pip install -r requirements.txt

# Copy the .env template
cp .env.example .env        # Then fill in your secrets
```

### 3. Setup the Frontend

```bash
cd site
npm install

# Copy the .env template
cp .env.local.example .env.local  # Then fill in your secrets
```

### 4. Run Locally

**Terminal 1 — Backend:**
```bash
cd backend
uvicorn main:app --reload --port 8000
```

**Terminal 2 — Frontend:**
```bash
cd site
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) 🚀

## 📱 Telegram Bot Command Reference

### Getting Started
1. Create a bot via [@BotFather](https://t.me/BotFather) on Telegram
2. Copy the bot token → paste into `TELEGRAM_BOT_TOKEN`
3. Find your user ID via [@userinfobot](https://t.me/userinfobot) → paste into `TELEGRAM_ADMIN_CHAT_ID`
4. Deploy the backend → message your bot `/start`

### Security Model
The bot implements a **strict single-admin lock**:
```python
def is_admin(chat_id: int) -> bool:
    return str(chat_id) == str(TELEGRAM_ADMIN_CHAT_ID)
```
Every handler checks this before executing. If the chat ID doesn't match, the message is silently ignored. **No one else can control your website.**

### Conversation Flows

The bot uses `ConversationHandler` with multi-step state machines:

```
/start → Main Menu
   ├── 📁 Add Project → [Title] → [Category] → [Image URL] → ✅ Published
   ├── 💼 Add Job     → [Title] → [Dept] → [Location] → [Type] → ✅ Posted
   ├── 📝 Generate Blog → [Topic] → 🤖 AI Writes → ✅ Published
   ├── 💬 Add Testimonial → [Name] → [Role] → [Quote] → ✅ Live
   ├── 📢 Broadcast   → [Message] → ✅ Sent to all subscribers
   ├── 🔧 Settings    → [Phone/Email/Notice/Maintenance/SEO/Privacy/Terms]
   └── 📊 Analytics   → 📸 Bar Chart + 🥧 Pie Chart sent to chat
```

       Title: "How India is Leading the Green Architecture Revolution"

        and 3 unread client inquiries."

The system prompt injects live data:

context_str = f"Projects: {len(projects)}, Jobs: {len(jobs)}, Inquiries: {len(msgs)}"

## 🚀 Deployment Guide

### Frontend → Vercel

```bash
# Option 1: Auto-deploy from GitHub
# 1. Push to main → Vercel auto-deploys

# Option 2: Manual
cd site
npx vercel --prod
```

**Required Vercel Settings:**
- Root Directory: `site`
- Build Command: `npm run build`
- Output Directory: `dist`
- Environment Variables: `VITE_API_URL`, `VITE_OPENROUTER_API_KEY`

### Backend → Render

Use the included `render.yaml`:
```yaml
services:
  - type: web
    name: vertical-constructions-backend
    runtime: python
    buildCommand: pip install -r backend/requirements.txt
    startCommand: cd backend && uvicorn main:app --host 0.0.0.0 --port $PORT
    disk:
      name: sqlite-data
      mountPath: /data
      sizeGB: 1
```

**Required Render Environment Variables:**
```
TELEGRAM_BOT_TOKEN
TELEGRAM_ADMIN_CHAT_ID
OPENROUTER_API_KEY
```

> ⚠️ **Critical:** Only ONE instance of the backend should ever run at a time. Running the backend locally while Render is also running will cause a `telegram.error.Conflict` crash. Use a separate dev bot token for local development.
